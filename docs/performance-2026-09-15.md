# 公開リンクの表示速度（2026-09-15）

対象は、現在稼働している `https://drawing-prompt-quiz.vercel.app/` のトップページ。
独自ドメイン `tsutawarukana.com` は 8.8.8.8 と 1.1.1.1 の両方で
`NXDOMAIN` だったため、現在のリンク先には使えない。

## 原因と修正

共通ヘッダーの `SiteHeader` がサーバー描画中に未確認回答の有無を取得していた。
その処理はリクエストの Cookie を読むため、公開トップも毎回動的に生成されていた。
修正前の本番では `Cache-Control: private, no-store`、
`x-vercel-cache: MISS` が6回とも返った。応答開始までの時間は 0.30～1.38 秒。

未確認の有無をブラウザから専用APIで取得するよう変更した。APIは利用者ごとの応答なので
`private, no-store` のままにし、トップのHTMLから利用者別の情報を外した。
ビルドではトップが静的ページ（`○ /`）になった。本番でも
`Cache-Control: public`、`x-vercel-cache: HIT` が連続6回返った。
応答開始までの時間は同じ端末からの6回で 0.13～0.80 秒。
Chromiumで新しいブラウザ状態から4回開いたところ、最初の内容表示を取得できた
3回は 0.21～0.90 秒だった。通信経路による揺れがあるため、これは全利用者の
待ち時間を保証する数値ではない。

DB移行後の構造・権限検査209件、ブラウザ全131件、公開サイトの読み取り検査18件は合格。
`/api/notices/unseen` の匿名応答は `false` で、`private, no-store` と `Vary: Cookie` を確認した。
