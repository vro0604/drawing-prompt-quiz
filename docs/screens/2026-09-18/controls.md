# 画面ごとの、押せるもの・入れるもの（2026-09-18 実測）

`node scripts/capture-screens.mjs` が撮った画面から、機械的に抜き出したもの。
この端末の中で動かした検証用のデータなので、絵は表示されず、名前も検証用のもの。
画面の枠組み・文言・押せるものは本物。

## どの画面にも出る枠

- 上の行: つたわるかな（トップへ）／お題を引く／作品／ランキング／アカウント
- 下の行: 利用規約／プライバシーポリシー
- 制作に挑戦している間だけ、いちばん上に時計の帯が出る（挑戦していない人には出ない）

## 撮った幅

- ノートパソコン幅: 横1280。ファイル名は `<画面の名前>.png`
- 手のひらの端末幅: 横390。ファイル名は `<画面の名前>-sp.png`
- 同じ状態のまま幅だけ変えて撮っているので、2枚の中身は必ず一致する
