| 消える | 透明化 | 結果がほぼ同じ。回答前だと言い換えになる |
| 遅い | 静か | 否定的な近さは無いが、動作の遅さと静けさは同時に読まれやすい |
| 高い | 高所 | ほぼ同義。回答前に出すと正解が確定する |
| 黒い | 黒猫 | 正解語を部分として含む方向の言い換え |

## 機械検査で拾えないもの

文字も読みも重ならない言い換え（「葬送」と「終わり」のような組）は、
上の禁止の組へ人が足すまで拾えません。
いま拾えている組は 126 組です。
