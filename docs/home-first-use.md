## 2. 行き先の実際（リポジトリと手元の画面で確かめた）

| 押す場所 | 行き先 | その先で起きること |
|---|---|---|
| お題を引く | `/play` | 未サインインでもモードと制作時間を選べる。「ドラフトを始める」を押した時点でゲストが発行される（`play/page.tsx`） |
| （ドラフトの途中） | `/play` | 同じ画面が、めくりかけの盤面を続きから出す |
| （お題を確定したあと） | `/prompt/<id>` | 制作時間の帯が全ページの上に出る。お題のページに「このお題で描いた作品を投稿する」→ `/works/new?promptId=…`。ゲストには「投稿にはアカウント登録が必要です」と出る |
| 作品に答える | `/works` → `/works/<id>` | 一覧も回答もゲストのままできる。回答を送る瞬間にゲストが発行される |
| 描いた絵で試す | `/works/import` | お題を引かずに手元の絵を出す入口。投稿には登録が要る |

確定したお題を持っているかは `/api/challenge`（全ページの時計の帯が読む窓口）が返す。
未サインインの人には `null` を返すだけで、利用者を発行しない（`features/challenge/rpc.ts`）。

## 4. 決めた形

### 文言

| 場所 | 文 |
|---|---|
| 見出し | あなたの絵、何を描いたか伝わる？ |
| 1文 | 引いて、描いて、答える。 |
| 補足 | 描く人と見る人で、何が伝わったかを確かめるお絵描きサービス。 |
| 手順の下 | 答えが集まると、描いた人に「どう伝わったか」が分かります。 |
| ボタンの下 | 登録なしで始められます。登録が要るのは作品を投稿するときだけです。 |

いずれもユーザー指示の第一候補のまま。上手さの採点に読める語は使っていない。

### 3つの手順（`src/app/_home-steps.tsx`）

| 手順 | 絵記号 | 一言 | 行き先 |
|---|---|---|---|
| 引く | お題札（伏せた札の上に表の1枚） | お題カード | `/play` |
| 描く | 紙とペン | 絵を描く／**確定したお題を持つ人は「描きかけへ」** | `/play`／**そのお題のページ `/prompt/<id>`** |
| 答える | 4つの選択肢の1つに印 | 絵から当てる | `/works` |

「描く」の行き先だけは人によって変わる。ページは静的に配ったまま、表示後に `/api/challenge` を1回読んで差し替える
（読めなかったら /play のまま）。ドラフトの途中の人は /play を開けば盤面が続きから出るので /play のまま。

### 最初の一手

- 主ボタンは「お題を引く」1つだけ（→ `/play`）
- 答えるだけの人のために、枠だけの副ボタン「描かずに、絵に答える」（→ `/works`）
- 「描いた絵で試す」はボタンから文字の入口へ下げた（行き先は同じ `/works/import`）
- 登録を求める位置は変えていない（投稿の直前のまま）

### 幅ごとの組み立て

| 幅 | 組み立て |
|---|---|
| スマホ（390px） | 見出し → 1文 → 補足 → 手順3つを横一列 → 一言 → 主ボタン → 副ボタン、が最初の画面に収まる |
| 小さいスマホ（320px） | 手順3つまでが最初の画面。ボタンは少し下（ヘッダーの行き先が3段に折り返すため）。はみ出し 0px |
| PC（1280px） | 本文の幅を 672px に絞り、手順の四角を 170px 前後にする。ボタンは横一列で中央 |

## 5. 確かめたこと

ブラウザ（手元のアプリ。本番へは接続しない）で、ゲストとして次を通した。

- トップ → 「引く」→ /play → ドラフトを始める → カードをめくる → **途中でトップへ戻ると「描く」は /play** →「引く」で盤面が続きから出る
  → 確定 → /prompt/<id> → トップへ戻ると「描く」が /prompt/<id>（一言は「描きかけへ」）→ 押すとお題のページ →
  「このお題で描いた作品を投稿する」→ 「投稿にはアカウント登録が必要です」（従来どおり）
- トップ → 「答える」→ /works → 作品 → 4問に長押しで答えて送る → 結果が出る（登録を求められない）
- 320 / 390 / 1280px、明るい地と暗い地で撮って見た。はみ出し 0px、手順の四角は 101×138px（390px）

ブラウザ試験（`test/e2e/browser.mjs` の A 群）に2件足した。
初見の人の行き先と押す場所の大きさ（320px）、確定したお題を持つ人の「描く」の行き先。
