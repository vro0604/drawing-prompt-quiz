配色の決まりごとがどう決めているかを調べ、docs/RESEARCH/2026-08-31_主色の決め方.md に

調べる題材にこれを選んだのは、docs/PENDING.md の 2 番「主色を何にするか」が
「1 番が決まってから」で保留になったまま、その 1 番（紙・掲示板寄りで進める）が
2026-08-27 に決まったのに出し直されていないため。
docs/RESEARCH/ にはまだ1本も報告が無く、今日が1本目。

8件のうち6件は、配布元の公開リポジトリを複製してソースの原本を直接読んだ
（GOV.UK Design System 、デジタル庁のデザイントークン 、Excalidraw 、PaperCSS 、
Tufte CSS 、Radix Colors）。読んだ版の番号と日付を報告に書いてある。
残り2件（note 、Cosense）は検索結果の説明文しか読めていないので、
そのことを事例ごとに明記した。

そのままでは判断に足りないので、色の読みやすさ（コントラスト比）を自分で計算し、
2つの表にした。1つは主色の候補11色が白と紙色の地でどうなるかの表、
もう1つはいまの src/app/globals.css が持つ文字の3段が、地を紙色に変えたとき
どう動くかの表。

いちばん効く結果は次の2つ。

- 地を白から紙色に変えても、いまの文字の下限（黒 55 パーセント）は
  4.74 から 4.68 になるだけで、基準の 4.5 を割らない。
  地を変える作業は、文字の設計をやり直す作業を連れてこない。
- 一方で、純白を前提に選ばれた色は、地を紙色にした瞬間に基準を割ることがある。
  実例が3つ出た。Radix の blue11 #0d74ce は 4.77 から 4.49 、
  デジタル庁の SolidGray-536 #767676 は 4.54 から 4.28 、
  同じく Red.800 #ec0000 は 4.60 から 4.37 。
  他所の値を借りるときは、こちらの地で計算し直す必要がある。
