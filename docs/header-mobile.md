対象は全ページの上にある枠（`src/app/_shell.tsx` と `src/app/_site-nav.tsx`）。

## 0. 結論

狭い画面では、ヘッダーに出すものを「つたわるかな」とメニューのボタンの
2つだけにした。行き先5つはボタンを押したときにヘッダーの直下へ開く。
広い画面（640px 以上）の横並びは、**位置まで含めて1px も変えていない。**

| 幅 | 直す前の段数・高さ | 直したあとの段数・高さ | 見出しが出る位置 |
| --- | --- | --- | --- |
| 320px | 3段・157px | 1段・61px | 181px → 85px |
| 375px | 3段・157px | 1段・61px | 181px → 85px |
| 390px | 2段・109px | 1段・61px | 133px → 85px |
| 430px | 2段・109px | 1段・61px | 133px → 85px |
| 640px | 1段・61px | 1段・61px | 117px（変化なし） |
| 768px | 1段・61px | 1段・61px | 117px（変化なし） |
| 1280px | 1段・61px | 1段・61px | 117px（変化なし） |

「見出しが出る位置」は、トップの `<h1>`（「あなたの絵、何を描いたか伝わる？」）の
上端が画面のいちばん上から何 px の所に来るか。320px で 96px ぶん上がった。

## 1. 直す前の実測

測り方: この端末の Chromium（ブラウザ試験と同じもの）で、検証用のサーバーに
つないだトップを幅ごとに開き、`header[data-site-nav]` の中の押せるものの
y 座標を数えて段数にした（2026-09-18）。

- 折り返しが始まる幅: **536px より狭いとき。** 400px から 800px まで 8px 刻みで
  測り、528px までが2段、536px から上が1段だった。
- 320px と 375px では3段（157px）。390px と 430px では2段（109px）。
- 横へのはみ出しはどの幅でも 0px。折り返していただけで、壊れてはいなかった。

### 何がどこにあったか

- `src/app/_shell.tsx` … ヘッダーとフッターの中身。行き先の並びもここ。
- `src/app/_notice-entry.tsx` … 「知らせ」の入口。未確認があるかどうかだけを
  ブラウザから聞く（D192）。位置（右端へ寄せる）も大きさもこの中に書いてあった。
- 行き先は5つ: `/play` お題を引く、`/works` 作品、`/rankings` ランキング、
  `/notices` 知らせ、`/account` アカウント。
- 現在のページを示す印は**無かった**（5つとも同じ見た目）。
- 折り返しの制御は `flex-wrap` と `gap-y-1` だけで、畳む仕組みは無かった。

### 採用した3件と、取ったもの

1. Stripe — 閉じているときヘッダーに置くのは2つだけ、という決め方。
   ボタンに `aria-expanded` を持たせること。押すと絵が×に変わること。
   行と行のあいだに細い線を引くこと。
2. Notion — 44×44のボタンを右端に置くこと。板は白（本文と同じ地）にすること。
3. Tailwind CSS — 開いた板の1行を48px以上にして、文字は左揃えにすること。

3件とも**全画面を覆う**作りだが、そこは採っていない。行き先が5つしかなく、
いま居るページを隠す必要が無いため（開いたときの板の高さは241px）。
色・ロゴ・字面はどこからも持ってきていない。

## 3. 決めた形

### 切り替える幅

`sm`（640px）。このリポジトリが既に使っている区切りで、新しく増やしていない。
折り返しが起きるのは 536px より狭いときなので、640px で畳めば折り返す幅は
全部入る。640px 以上では、これまでどおりの横並び。

### 閉じているとき（640px 未満）

- 1行だけ。左に「つたわるかな」（/ へ）、右にメニューのボタン1つ。
- ボタンは 44×44、角の丸い枠付き、中は三本線。
- ヘッダー全体の高さ 61px。

### 開いたとき

- ヘッダーの直下に、画面の幅いっぱい（左端0px・右端まで）の板が出る。
- 地は本文と同じ色。上に1本の線、行と行のあいだにも薄い線。
- 5つの行き先を縦に1列。1行48px。
- 板の高さ241px（5行＋線）。開いてもヘッダーの高さは302pxで、
  下にある本文を覆わずに押し下げる。
- 全画面を覆わない。画面下から出す形にもしていない。

### 中身（並びも意味も変えていない）

| 順 | 文言 | 行き先 | 備考 |
| --- | --- | --- | --- |
| 1 | お題を引く | /play | |
| 2 | 作品 | /works | |
| 3 | ランキング | /rankings | |
| 4 | 知らせ | /notices | 未確認があれば太字（D192・数字も丸も出さない） |
| 5 | アカウント | /account | ゲストでも押せる。中身は従来どおり |

新しいページも新しい行き先も作っていない。現在のページを示す印は、
もともと無かったので今回も付けていない。

### 開け閉て

- ボタンを押すと開く。もう一度押すと閉じる。
- 行き先を押すと、閉じてから移る。
- Escape で閉じ、焦点はボタンへ戻る。
- メニューの外を押しても閉じる。
- 別のページへ移ったとき（戻る・進むを含む）は開いたままにならない。
- 読み上げには `aria-expanded`（開いているか）と `aria-controls`（どれが開くか）、
  ボタンの名前（「メニューを開く」「メニューを閉じる」）で伝える。

- 暗い配色でも板の地と線が出る（320px と 390px で確認）。
